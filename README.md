# Імітаційна модель системи забезпечення надійності АСУ ТП з резервним комп'ютером

Код до курсової роботи з дисципліни «Моделювання систем»: імітаційна модель системи забезпечення надійності АСУ ТП з резервним комп'ютером на основі формального опису мережею масового обслуговування.

Основний комп'ютер обробляє дані про технологічний процес, резервний перебуває в «гарячому резерві» і після виявлення відмови основного підключається замість нього. Модель оцінює середній час перебування технологічного процесу в загальмованому стані та середню кількість пропущених через відмови даних, а також досліджує вплив періоду сигналу працездатності і тривалості підключення резервного комп'ютера.

Алгоритм імітації (просування часу за принципом найближчої події), статистична обробка, критерій згоди χ² і регресійний аналіз реалізовані власним кодом, без сторонніх бібліотек.

## Запуск

Потрібна Java 17 або новіша.

```sh
./run.command
```

або вручну з цієї папки:

```sh
javac -encoding UTF-8 -d build asutp/*.java
java -cp build asutp.Main results         # протокол подій і верифікація
java -cp build asutp.Experiment results   # експериментальне дослідження
java -cp build asutp.Proposals results    # пробні запуски пропозицій
```

Усі прогони мають фіксовані початкові значення генератора (seed), тому повторний запуск дає ті самі файли в `results/`.

## Класи (`asutp/`)

Модель:

| Клас | Призначення |
|---|---|
| `Params` | Вхідні змінні і параметри моделі |
| `FunRand` | Генератор рівномірно розподілених величин unif(d, s) |
| `Arrival` | Надходження вимог «набір даних» |
| `Device` | Пристрій обслуговування без черги (D1–D5) |
| `Model` | Мережа масового обслуговування і алгоритм її імітації |
| `Stats` | Збір статистики і обчислення вихідних характеристик |
| `Main` | Протокол подій і прогони верифікації |

Експериментальне дослідження:

| Клас | Призначення |
|---|---|
| `Experiment` | Перехідний період, серія замірів, закон розподілу, план 5 × 5 |
| `StatMath` | Середнє, стандартне відхилення, точність, критичні значення χ², F, t |
| `Distribution` | Гістограма частот і критерій згоди χ² |
| `Regression` | Метод найменших квадратів, індекс кореляції, критерії Фішера і Ст'юдента |
| `Proposals` | Пробні запуски пропозицій щодо поліпшення системи |
